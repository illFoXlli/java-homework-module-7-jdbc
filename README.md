# JDBC Module 6

## 📌 Description
This project demonstrates working with a database using JDBC.

## 🛠 Technologies
- Java
- JDBC
- H2 Database
- Gradle

## 📁 Structure
- `sql/init_db.sql` — create tables
- `sql/populate_db.sql` — insert data
- `sql/find_*.sql` — select queries
- `Database` — connection singleton
- `DatabaseQueryService` — query execution

## ▶ How to run

1. Run `DatabaseInitService`
2. Run `DatabasePopulateService`
3. Run `Main`
